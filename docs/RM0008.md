🧩 1. CPU core
- Thành phần :
	- Cortex-M3: nơi thực thi mã lệnh, xử lý dữ liệu 
	- ICode: là bus để CPU truy cập bộ nhớ (flash), dùng để lấy mã lệnh CPU thực thi
	- DCode: là bus để CPU truy cập dữ liệu thường dùng để truy cập SRAM hoặc thiết bị ngoại vi
	- System interface: là giao diện hệ thống cho phép CPU truy cập các thành phần điều khiển hệ thống như:
		- Bộ điều khiển ngắt (NVIC)
		- Bộ định thời hệ thống (SysTick)
		- Các thanh ghi hệ thống
		- Các khối quản lý xung nhịp và reset (RCC)

	- DMA interface: Là giao diện kết nối giữa CPU và bộ điều khiển DMA. Cho phép CPU cấu hình DMA để truyền dữ liệu giữa 
	bộ nhớ và thiết bị ngoại vi mà không cần CPU can thiệp trực tiếp vào quá trình truyền.
	
<details>
<summary>DMA</summary>	

- DMA (Direct Memory Access – Truy cập bộ nhớ trực tiếp) là một cơ chế trong vi điều khiển cho phép dữ liệu được truyền giữa 
bộ nhớ và ngoại vi, hoặc giữa các vùng bộ nhớ với nhau, mà không cần CPU xử lý từng bước. CPU chỉ cần cấu hình bộ điều khiển DMA, 
sau đó DMA sẽ tự động thực hiện việc truyền dữ liệu, giúp giảm tải cho CPU và tăng hiệu suất hệ thống.
- DMA Controller: Bộ điều khiển DMA nằm trong vi điều khiển, chịu trách nhiệm quản lý quá trình truyền dữ liệu.
- Cách hoạt động: CPU thiết lập địa chỉ nguồn, địa chỉ đích, số lượng dữ liệu cần truyền, rồi kích hoạt DMA. Sau đó, DMA tự động 
thực hiện việc đọc/ghi dữ liệu.
Kết quả: CPU có thể làm việc khác trong khi DMA xử lý dữ liệu, giúp hệ thống chạy song song hiệu quả hơn.

</details>

📦 2. Khối bộ nhớ nội bộ và giao tiếp bộ nhớ ngoài  
**Thành phần:**  
- Flash (qua FLITF)  
- SRAM  
- FSMC (giao tiếp bộ nhớ ngoài)  
- SDIO (giao tiếp thẻ SD)  

**Cách đọc:**  
- Flash chứa chương trình, SRAM chứa dữ liệu tạm.  
- FSMC và SDIO cho phép mở rộng bộ nhớ ngoài. 
🚚 3. Khối DMA (Direct Memory Access)  
**Thành phần:**  
- DMA1 (Ch.1 → Ch.7)  
- DMA2 (Ch.1 → Ch.5)  

**Cách đọc:**  
- DMA giúp truyền dữ liệu giữa bộ nhớ và thiết bị ngoại vi mà không cần CPU.  
- Mỗi kênh DMA có thể cấu hình riêng cho từng luồng dữ liệu.  

🔀 4. Bus Matrix và hệ thống bus  
**Thành phần:**  
- Bus Matrix  
- AHB System Bus  
- Bridge 1 → APB1  
- Bridge 2 → APB2  

**Cách đọc:**  
- Bus Matrix là trung tâm kết nối dữ liệu.  
- AHB là bus tốc độ cao, APB1/APB2 là bus tốc độ thấp cho thiết bị ngoại vi.  

🧩 5. Khối ngoại vi APB2  
**Thành phần:**  
- ADC1–3, USART1, SPI1, TIM1, TIM8  
- GPIOA–G, EXTI, AFIO  

**Cách đọc:**  
- Đây là các thiết bị ngoại vi tốc độ cao.  
- GPIO là cổng vào/ra số, ADC là chuyển đổi analog → số, USART là giao tiếp nối tiếp.  

🧩 6. Khối ngoại vi APB1  
**Thành phần:**  
- DAC, USB, I2C1–2, UART4–5, USART2–3  
- TIM2–6, SPI2/3, RTC, Watchdog (IWDG, WWDG)  

**Cách đọc:**  
- Thiết bị ngoại vi tốc độ thấp hơn.  
- DAC là chuyển đổi số → analog, RTC là đồng hồ thời gian thực, Watchdog giúp reset khi hệ thống treo.
